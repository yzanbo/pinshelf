# 手で確かめること

画面の操作は自動のテストで確かめにくいので、変えたところに関係する項目を、`make run` で起動して手で確かめます。操作のくわしい決まりは [USAGE.md](USAGE.md) を見てください。

## 基本の流れ

- [ ] Finder からファイルをドラッグし始めると、画面の端に細い帯が出る
- [ ] カーソルを端の帯に近づけると棚が開き、ドロップできる
- [ ] 左の端に近づけると、帯が左の端へ移る（「カーソルに近いほう」の設定のとき）
- [ ] ドロップしたあと棚から離れると、件数つきの帯にたたむ。帯にポインタを乗せると開く
- [ ] ドラッグ中に軽く振ると、カーソルの位置に棚が出る。何も置かずにドラッグを終えると消える
- [ ] 棚からほかのアプリ（Finder・メールなど）へドラッグで取り出せる
- [ ] テキストや Safari のリンクも置ける
- [ ] 設定（メニューバー → 設定…）で出し方を変えると、次のドラッグから反映される
- [ ] フルスクリーンのアプリの上・別のデスクトップでも棚が出る
- [ ] アクセシビリティなどの権限を求められない

## 画面の端の帯の場所

- [ ] 「カーソルの高さ」で、Finder からドラッグすると、出たばかりの帯がカーソルの高さについてくる
- [ ] 端に近づけると、その高さで棚が開き、開いたあとは動かない
- [ ] 「上」「下」にすると、端の上・下に出る
- [ ] 「下」で出た棚を見出しで上のほうへ運んでおくと、次のドラッグでも、運んだ高さのまま（下へ戻らない）
- [ ] 画面の端の棚は、端に寄せただけでは開かず、帯の近く（上下も含めて）に来たときに開く。真ん中で作って端にしまった棚と同じ

## キーで出す

- [ ] Finder からドラッグ中に ⇧ を押すと、カーソルの位置に棚が出る
- [ ] ⇧ を押しながらファイルを選んでそのままドラッグしても、すぐには出ない（離して押し直すと出る）
- [ ] 設定で「使わない」にすると、押しても出ない

## 自動では出さないアプリ

- [ ] 一覧に入れたアプリの中でドラッグしても、棚が出ない（振っても出ない）
- [ ] ほかのアプリでは、これまでどおり出る

## 画面の端の棚

- [ ] ドラッグを始めて端に寄せると、振って出す棚と同じ見た目の棚が出る（✕・▭・…・› がある）
- [ ] ▭ ボタン（またはダブルクリック・真ん中へ運ぶ）で浮いた棚になり、中身・名前・色が残る。次のドラッグでは新しい画面の端の棚が出る
- [ ] ✕ で閉じると、メニューバーの「最近閉じた棚」から開き直せる
- [ ] 振って出した棚を画面の端にしまってから、別のファイルをドラッグして端に寄せると、新しい帯は出ずに、しまった棚が開く
- [ ] そのとき振ると、新しい棚が開く
- [ ] 中身を全部取り出して棚からポインタを離すと、帯も消える
- [ ] 端の近くで放すと、端に戻る
- [ ] 前のバージョンで画面の端の棚に入れていた中身が、起動し直しても残っている

## 浮いた棚を画面の端にしまう

- [ ] 浮いた棚の上の帯をつかんで画面の端まで運ぶと、端の細い帯になる
- [ ] 帯にポインタを乗せると棚が開き、離れると帯にたたむ
- [ ] Finder からドラッグして帯に近づけると棚が開き、落とせる
- [ ] 開いた棚を端から離して放すと、浮いた棚に戻る
- [ ] しまった棚を 2 つ同じ高さに置こうとしても、帯が重ならない
- [ ] しまったまま終了して起動し直すと、しまったまま戻る
- [ ] 「画面の端まで運んだら、自動でしまう」をオフにすると、画面の端まで運んで放しても、しまわずに画面の中に戻る。しまうボタンではしまえる

## 画面の端で開いたままにする（見出しのピン）

- [ ] 画面の端にある棚の見出しにピンが出る。浮いている棚には出ない
- [ ] ピンをオンにすると、ポインタを離しても開いたまま。オフにすると、ポインタを離したらすぐに帯にたたむ
- [ ] たたんである帯の棚で、… メニューから「画面の端で開いたままにする」を選ぶと、すぐに開く
- [ ] 設定の「新しい棚は、画面の端で開いたままにする」をオンにしてファイルをドラッグすると、画面の端の棚が最初から開いて出る。すでに出ている棚は変わらない
- [ ] ピンの状態は、終了して起動し直しても棚ごとに残っている
- [ ] 開いた棚の … メニューを開いて、棚の外にはみ出したメニューの上へポインタを動かしても、たたまない
- [ ] 画面の端から開いた棚の見出しをつかんで真ん中へ運ぶと、途中でたたまず、放したところで浮いた棚になる

## 中身を見る・選ぶ

- [ ] 棚のファイルを押してスペースキーを押すと Quick Look が出る。もう一度押すと閉じる
- [ ] Quick Look のパネルが、ほかのアプリのウィンドウや棚の後ろに隠れない
- [ ] 1 つだけ見ているとき、矢印キーで隣のものに切り替わる
- [ ] 複数選んでスペースキーを押すと、Quick Look の中で切り替えられる
- [ ] 画面の端の棚で Quick Look を見ている間、ポインタが棚から離れても帯にたたまない
- [ ] 棚を押したあと、元のアプリに戻ると文字を打てる（棚がキー入力を取り続けない）

## 取り出す

- [ ] 棚のファイルを同じディスクのフォルダへ落とすと移動し、棚から消える
- [ ] ⌥ を押しながら落とすとコピーになり、棚に残る
- [ ] 外付けのディスクへ落とすとコピーになり、棚に残る
- [ ] 複数選んでドラッグすると、まとめて取り出せる
- [ ] Dock のゴミ箱に落とすとゴミ箱に入り、棚から消える
- [ ] テキスト・リンクも、ほかのアプリへ取り出せる
- [ ] 浮いた棚から別の浮いた棚・画面の端の棚へ落とすと移り、元の棚から消える
- [ ] ⌥ を押しながら棚から棚へ落とすと、両方の棚に残る
- [ ] 同じ棚の上で落としても、消えない
- [ ] 移した先の棚の中身が、再起動後も戻る

## ロック・スタック・元に戻す

- [ ] 右クリックの「ロック」で鍵の印が付き、⌥ を押さずに Finder へ移動で取り出しても棚に残る（新しい場所を指している）
- [ ] 複数のファイルを一緒に置くとスタックになり、つかむとまとめて取り出せる
- [ ] スタックを分けると、1 つずつ並ぶ
- [ ] 棚から外したものを ⌘Z で戻すと、元の位置に戻る
- [ ] 設定の「中身」→「コピーで取り出したものも、棚から外す」をオンにすると、コピーで取り出しても棚から外れる（ロックしたものは残る）

## クリップボードから棚へ

- [ ] Finder でファイルをコピーして ⌥⇧V を押すと、カーソルの位置に棚が開いて入る
- [ ] スクリーンショットをクリップボードに撮って（⌃⇧⌘4）⌥⇧V を押すと、画像のファイルとして入る
- [ ] 棚を押してから ⌘V を押すと、その棚に入る
- [ ] クリップボードが空のときは、メニューの「クリップボードから棚へ」が選べない

## メニューバー

- [ ] Finder のファイルをメニューバーのアイコンに落とすと、アイコンの下に棚が開いて入る
- [ ] 設定で「画面の端の棚に入れる」にすると、画面の端の棚に入り、少しのあいだ開く
- [ ] アイコンを押すとメニューが出て、「設定…」で設定画面が前面に開く

## アップデート

- [ ] メニューバーのメニューに「アップデートを確認…」が出る（公開鍵の入ったビルド）。選ぶと、Dock にアイコンが出て、「アップデートを確認中…」の小窓が前面に出る。小窓は一瞬で閉じず、少なくとも 0.5 秒は出てから結果の画面に替わる。閉じると、Dock から消える
- [ ] 設定の「一般」→「アップデート」に、「新しい版を自動で確かめる」・バージョン・「アップデートを確認…」・最後に確かめた日時が出る
- [ ] 公開鍵の入っていないビルド（`project.yml` の `SUPublicEDKey` が空）では、メニューの項目が出ず、設定には版と「使えません」の説明だけが出る
- [ ] 入れ替えそのものは、下の「更新を通しで試す」で確かめる

### 更新を通しで試す

リリースの前や、更新まわり（Sparkle の版・署名・許可）を変えたときに、手元で実際に入れ替えて確かめます。ふだんの Pinshelf とは別の ID（`app.pinshelf.UpdateTest`）・別の名前（`PinshelfUpdateTest`）の試験用アプリを使うので、ふだんの棚や設定には触れません。更新ファイルの署名の鍵もその場で作るので、リリース用の鍵がなくても試せます。

1. `make stop` で、ふだんの Pinshelf を終了する（同じ見た目のアイコンが 2 つ出ないように）
2. `make update-test` を流す。古い版と新しい版の試験用アプリを作り、新しい版を手元のサーバー（`http://localhost:8765`）から配り始める
3. 画面に出る 2 通りのどちらかで、古い版を開く
   - **手早く試す**: 手元でビルドした古い版（`build/update-test/old/PinshelfUpdateTest.app`）を、そのまま開く。更新まわりのコードを変えたときに。プロジェクトが「書類」などのフォルダの中にあると、入れ替えのときに macOS が「フォルダ内のファイルにアクセス」を確かめるので、許可する（入れ替えの部品が、そのフォルダの中のアプリを書き換えるため。配る版はアプリケーションフォルダに置くので、出ない）
   - **配る形に近づけて試す**: 古い版をブラウザでダウンロードし、アプリケーションフォルダに入れて、「このまま開く」で開く。ダウンロードの印（quarantine）が付いたままの版から更新できるかを確かめる。止められずに開いたときは、そのまま進めてよい（手元のサーバーからのダウンロードでは印が付かないことがあり、この Mac で一度開いた版は止められないこともある）。あとから `xattr -w` で印を付けると、別の場所に写して動かす扱い（App Translocation）になって更新できなくなるので、付けない。リリースの前と、Sparkle の版や署名を変えたときに
4. 棚にファイルを 1 つ置き、設定の「一般」で「ログイン時に起動」をオンにする
5. メニューバーのアイコンに小さな丸が付く。メニューのいちばん上の「新しいバージョン … があります…」を選び、「アップデートをインストール」→「インストールして再起動」と進む（試験用アプリは、前に確かめてから 1 時間たっていないと丸が付かない。そのときは「アップデートを確認…」で進める）

確かめること:

- [ ] 自動で新しい版を見つけて、画面を割り込ませずに、アイコンの丸とメニューで知らせる（試験用アプリでは、初めて開いたときか、前に確かめてから 1 時間以上たっているとき。記録には `Found version …: showing the menu bar badge` と残る）
- [ ] 新しい版が開き直すときに、macOS の確認の画面（「開発元を確認できない」や、前の版のデータを開いてよいかの確認）が出ない
- [ ] 設定の「一般」のバージョンが、新しい版になっている
- [ ] 棚に置いたファイルが残っていて、開ける（ダブルクリック・Quick Look）
- [ ] 「ログイン時に起動」がオンのまま
- [ ] もう一度「アップデートを確認…」を選ぶと、「最新版を使用しています」と出る

終わったら:

1. 設定の「一般」で「ログイン時に起動」をオフに戻してから、試験用の Pinshelf を終了する（戻し忘れたときは、システム設定 →「一般」→「ログイン項目」で外す）
2. アプリケーションフォルダに入れた `PinshelfUpdateTest.app` は、ゴミ箱に入れる
3. サーバーを control + C で止める
4. 試験用のデータも消すときは、`~/Library/Containers/app.pinshelf.UpdateTest` を削除する（Finder で消すときは、ふだんの Pinshelf の保存場所 `app.pinshelf.Pinshelf` と取り違えないように、フォルダの場所で確かめる。作ったアプリは `build/update-test` にあり、`make clean` で消える）

試験のあいだの macOS の記録は、`make update-test-log` で `build/update-test/system.log` に書き出せます（直近 30 分。`SINCE="2026-11-26 19:50:00"` のように、いつからかを渡せる）。Sparkle の入れ替えの部品の記録と、macOS の側（許可の確認・サンドボックス・ログイン項目など）が試験用アプリについて出した記録が入るので、確認の画面が出たかの裏取りと、うまくいかないときの手がかりになります。アプリも、起動のたびに「版・『ログイン時に起動』の状態」と「棚のファイルをどう戻せたか（ブックマークで何個・パスで何個・見つからず何個）」を記録に残すので、入れ替えのあとに引き継がれたかも、ここで確かめられます。

証明書で署名した版どうしの更新を試すときは、`make update-test SIGN_IDENTITY="Pinshelf Dev"` のように証明書の名前を渡します（なければ、アドホック署名）。macOS はサンドボックスの保存場所をアプリの署名にひも付けるので、このときは ID と名前の後ろに `Signed` を付けて、保存場所を分けます。

棚のファイルや「ログイン時に起動」が引き継がれなかったとき、開き直すたびに確認の画面が出るときは、配る版を、決まった自己署名の証明書で署名する形に変える（ARCHITECTURE.md の「更新」）。

## 棚の大きさ

- [ ] 浮いた棚の右下の角をつかんで運ぶと、左上を動かさずに大きくなる
- [ ] 左の辺・上の辺でも変えられ、反対側の辺は動かない
- [ ] 縁にポインタを乗せると、その辺・角が光る（ほかのアプリを使っている間も）
- [ ] 棚を一度クリックしたあとは、縁にポインタを乗せると、大きさを変える形のポインタになる
- [ ] 小さくしすぎても、見出しのボタンが隠れない大きさ（幅 150）で止まる
- [ ] 狭くしても「1 個」が折り返さない。名前の長い棚は名前が「…」で省かれ、件数は残る
- [ ] 右端の画面の端の棚は、左の辺・上下の辺で変えられる（右の辺ではつかめない）
- [ ] 大きくした画面の端の棚を閉じたあと、次のドラッグで出る画面の端の棚も同じ大きさ
- [ ] 画面の端にくっついた棚の … メニュー →「大きさ」の見出しが「画面の端にあるときの標準」、浮いた棚では「浮いているときの標準」になる
- [ ] 画面の端と浮いているときで大きさを変えておくと、しまう・浮かせるたびに、それぞれの大きさに切り替わる
- [ ] 設定の「棚」→「棚の大きさ（標準）」で画面の端にあるときと浮いているときに別々の大きさを入れると、それぞれその大きさで開く
- [ ] 「縁をつかんで変えた大きさを、標準にする」をオフにすると、縁で大きさを変えても次の棚は標準の大きさで開く
- [ ] … メニューの「大きさ」→「標準の大きさに戻す」で、棚が標準の大きさに戻る
- [ ] … メニューの「すべての棚」の見出しの下で「画面の端まで運んだら、自動でしまう」「新しい棚は、画面の端で開いたままにする」を切り替えると、設定画面のスイッチも変わる
- [ ] 振って出した棚を大きくすると、次に振って出す棚も同じ大きさ
- [ ] 終了して起動し直しても、それぞれの棚が同じ大きさで戻る

## 名前・色・お気に入り

- [ ] 「…」→「名前を変える…」で名前を入力すると、見出しに名前が出る
- [ ] 色を選ぶと、見出しの点・枠・しまった帯に色が付く
- [ ] 見出しの左に、お気に入りでない棚は ☆（線だけ）、お気に入りの棚は黄色の ★ がいつも出ている
- [ ] ☆ を押すと黄色の ★ になってお気に入りになり、もう一度押すと ☆ に戻る
- [ ] お気に入りにして × で隠すと、メニューバーのメニューの「お気に入りの棚」に出て、選ぶとまた出る
- [ ] 幅 150 の画面の端の棚に「元に戻す」ボタンが出ていても、★ や名前がほかのボタンに重ならない
- [ ] お気に入りの棚は、空のまま隠して再起動しても、メニューに残っている
- [ ] メニューバーの「お気に入り一覧…」で一覧が開き、ダブルクリックで棚が出る
- [ ] 一覧の右クリック →「お気に入りから削除」で一覧から消える。閉じていた棚は「最近閉じた棚」から開き直せる
- [ ] メニューバーの「お気に入りから削除 ▸」で選んだ棚が、メニューのお気に入りから消える
- [ ] メニューバーのお気に入りの棚をふつうにクリックすると、棚が出る（削除はされない）

## 最近閉じた棚

- [ ] 中身のある浮いた棚を閉じると、メニューの「最近閉じた棚」に出る
- [ ] 選ぶと、閉じたときの位置に中身ごと戻る
- [ ] 再起動しても、「最近閉じた棚」から開き直せる
- [ ] 「履歴を消す」で一覧が空になる

## ログイン時に起動

- [ ] 「ログイン時に起動」を入れると、システム設定 → 一般 → ログイン項目に Pinshelf が出る
- [ ] ログアウトしてログインし直すと、Pinshelf がメニューバーに出る
- [ ] システム設定で外してから設定画面に戻ると、スイッチも切れている

## 再起動したとき

- [ ] スクリーンショットをクリップボードから棚に入れてから、その画像を棚から外し（⌘Z で戻せることも確かめる）、棚を閉じて「最近閉じた棚」の「履歴を消す」を選ぶと、少しあとに `~/Library/Containers/app.pinshelf.Pinshelf/Data/Library/Application Support/Pinshelf/Clipboard/` から画像が消える
- [ ] ファイル・テキスト・リンクを棚に置いて終了し、もう一度起動すると戻っている
- [ ] 戻したファイルを、棚からほかのアプリへ取り出せる
- [ ] 終了している間にファイルを移動・名前変更しても、新しい場所で戻る
- [ ] 浮いた棚を動かしてから終了すると、同じ位置に戻る
- [ ] 戻らなかったファイルがあるときは、Console.app で `app.pinshelf.Pinshelf`（category: persistence）のログを見る

## 動き

- [ ] 帯にポインタを乗せて開いたあと、ポインタを離すと、棚がすぐに動き出して、画面の端に向かってなめらかに止まる（一瞬で消えたり、最後に一気にしまわれたりしない）
- [ ] 画面の端の棚をたたむ・開く途中も、帯と棚が画面の端から離れない（帯が、縮んでから端へ動くように見えない）。左端・右端の両方で確かめる
- [ ] 帯にたたんだ棚の帯をつかんでも、見えていない棚の中身を取り出してしまわない
- [ ] 画面の端の棚: 帯にポインタを乗せると、帯が棚に変わりながら端から引き出しのように出る。離れると、端へ滑り込んで帯にたたむ
- [ ] 画面の端の棚: ドラッグを始めて端に寄せると、端の外から滑り込んで出る。何も置かずにドラッグを終えると、端の外へ滑り出て消える
- [ ] 浮いた棚: 振って出すと、ふわっと出る。✕ で閉じると、小さくなりながら消える
- [ ] しまった棚: 帯にポインタを乗せると、端から棚が引き出される
