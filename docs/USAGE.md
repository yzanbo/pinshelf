# 使い方

Pinshelf の操作の一覧です。概要は [README](../README.md) を見てください。

起動すると、メニューバーに Pinshelf のアイコンが出ます（Dock には出ません。設定・お気に入り一覧を開いている間だけ Dock に出ます）。

## 棚を出す

棚の出し方は、設定の「出し方」で選びます。画面の端に出す・振って出す・キーで出すは、それぞれ使う・使わないを決められます（全部切って、メニューバーだけで使うこともできます）。

| 出し方 | 動き |
|---|---|
| ドラッグを始める（画面の端に出す） | 画面の端に細い帯が出る。ドラッグしたまま帯の近くまで運ぶと棚が開き、そのまま落とせる |
| ドラッグ中にマウスを軽く振る | カーソルの位置に棚が出る |
| ドラッグ中に決めたキーを押す（初期設定は ⇧） | カーソルの位置に棚が出る（振るのが苦手なとき向け） |
| メニューバーの「新しい棚を開く」 | カーソルのある画面の真ん中に棚が出る |
| メニューバーの「画面の端の棚を開く」 | 画面の端の棚を開く |

- 何も置かずにドラッグを終えると、出た棚は閉じる（お気に入りの棚は残る）
- 振る・キーで出す棚は、1 回のドラッグで 1 つまで
- 画面の端にしまった棚がすでにあれば、ドラッグを始めても新しい帯は出さず、その棚が帯の近くに来たときに開く。振る・キーで出す棚は、いつも新しく開く

### 画面の端の帯の場所

| 設定 | 選べるもの |
|---|---|
| 出す端 | 右端・左端・カーソルに近いほう（近いほうなら、ドラッグ中に近づいた側の端へ移る） |
| 出すとき | ドラッグを始めたとき・画面の端に近づいたとき |
| 出す高さ | 上・中央・下・**カーソルの高さ**（初期設定）。カーソルの高さなら、帯を出したドラッグの間は、帯がカーソルの高さについてくる。端に近づくと、その高さで棚が開き、開いたあとは落としやすいように動かない |

出す端・出す高さは、新しく帯を出すときの場所です。出たあとの帯は、その高さ（見出しをつかんで運んだら、運んだ高さ）にとどまり、再起動してもそのまま戻ります。

### 振って出す・キーで出す

- 振って出すときの感度は、設定の「出し方」→「感度」で選ぶ
- キーは、使わない／⇧ Shift／⌃ Control／⌘ Command から選ぶ。決めたキー「だけ」を押したときに出す（ほかの修飾キーと一緒に押しているときは出さない）
- ドラッグを始めたときにもう押していたら、一度離して押し直したときに出す（⇧ を押しながら選んで、そのままドラッグしたときに出ないように）
- ⌥ は Finder で「コピー」を選ぶキーなので選べない。⌘ は「移動」を選ぶキーでもあるので、⇧ か ⌃ がおすすめ

### 自動では出さないアプリ

設定の「除外するアプリ」に入れたアプリでドラッグを始めたときは、画面の端の棚も振って出す棚も出しません（デザインツールなど、ドラッグをよく使うアプリ向け）。

- 「アプリを追加」から、起動中のアプリを選ぶか、「その他のアプリを選ぶ…」でアプリケーションフォルダから選ぶ
- 判断に使うのは、ドラッグを始めたときに前面にあるアプリ。キーで出す棚は、除外するアプリの中でも出る
- 棚から始まったドラッグ（棚から棚へ移すとき）は、いつも出す。メニューバーからは、いつでも棚を開ける

## 画面の端の棚

画面の端の棚は、振って出す棚と同じ棚を、画面の端にしまったものです。見た目・見出しのボタンは同じで、違うのはドラッグを始めたときに自動で出るところだけです。

| 操作 | 動き |
|---|---|
| ドラッグ中・ポインタが帯の近く（上下も含めて）に来る | 棚が開く。離れると、すぐに帯にたたむ |
| 帯を押す | 棚が開く |
| 見出しの ✕ | 棚を閉じる（「最近閉じた棚」から開き直せる。お気に入りの棚は隠す） |
| 見出しの ▭ ボタン・見出しをダブルクリック・見出しをつかんで真ん中のほうへ運ぶ | 浮かせる（中身・名前・色はそのまま、浮いた棚になる） |
| 見出しの ›（左端の棚では ‹） | 帯にたたむ |
| 見出しの …（見出しの右クリックでも） | 棚のメニューを出す（[棚のメニュー](#棚のメニュー)） |
| 開いた棚を端に沿って上下に運ぶ | 帯の位置を変える |

- 端に寄せただけでは開かない。開くのは、ドラッグ・ポインタが帯の近くに来たとき
- 中身を取り出して空になった棚は、帯を残さずに閉じる（お気に入りの棚は残る）
- 帯にもそのまま落とせる。帯の件数は、中身の数

## 浮いた棚を画面の端にしまう

振る・キー・メニューで出した浮いた棚も、画面の端にしまえます。

| 操作 | 動き |
|---|---|
| 見出しをつかんで、画面の左右の端まで運ぶ | その端にしまう（細い帯にたたむ） |
| 見出しのしまうボタン・見出しをダブルクリック | 近いほうの端にしまう |
| 開いた棚を端から離して放す | 浮いた棚に戻る |

- 設定の「棚」→「画面の端まで運んだら、自動でしまう」をオフにすると、端まで運んで放しても、しまわずに画面の中に収める。オフでも、見出しのしまうボタン・ダブルクリック・… のメニューからはしまえる
- しまった帯は、ほかの帯と重ならないように並ぶ
- しまったままかどうかと帯の位置も保存し、再起動してもしまったまま戻る

## 画面の端で開いたままにする（見出しのピン）

画面の端にある棚は、棚ごとに、細い帯にたたむか、開いたままにするかを選べます。見出しのピンで切り替えます（… メニューの「画面の端で開いたままにする」でも同じ）。

| ピン | 動き |
|---|---|
| オン（塗りつぶし・青） | 開いたまま。ポインタが離れても、ドラッグ中に端から離れてもたたまない |
| オフ（線だけ） | ふだんは件数つきの細い帯にたたんでおき、ドラッグやポインタが帯の近くに来たら開いて、離れたらすぐにまたたたむ |

- ピンは、画面の端にある棚の見出しにだけ出る。浮いた棚もピンの状態を覚えていて、画面の端にしまったときに効く
- 新しく出す棚のピンのはじめの状態は、設定の「棚」→「新しい棚は、画面の端で開いたままにする」で決める（初期設定はオフ）。オンなら、ドラッグで出る画面の端の棚も、最初から開いて出る
- ピンがオンでも、見出しの ›（‹）で帯にたためる
- メニューを開いている間・Quick Look で見ている間・名前を入力している間・大きさを変えている間・マウスのボタンを押している間は、ポインタが離れてもたたまない

## 中身を見る・選ぶ

| 操作 | 動き |
|---|---|
| クリック | 選ぶ（⌘ で足し引き、⇧ で範囲） |
| スペースキー・⌘Y | 選んでいるものを Quick Look で見る（もう一度押すと閉じる） |
| 矢印キー | 選ぶものを前後へ動かす。1 つだけ見ているときは Quick Look もついてくる |
| ダブルクリック・⌘O | 開く（テキストは Quick Look で見る） |
| ⌘A | すべて選ぶ |
| delete | 選んでいるものを棚から外す（ファイルそのものは消さない） |
| ⌘Z・見出しの ↩︎ | 最後に棚から外したものを戻す |
| ⌘L | 選んでいるもののロックを切り替える |
| ⌘V | クリップボードの中身をこの棚に入れる |
| esc | 選ぶのをやめる |
| 右クリック | Quick Look・開く・Finder で表示・ロック・スタックにする／分ける・棚から外す（何もないところでは「貼り付ける」） |

ファイルとテキストを Quick Look で見られます。リンクは開くだけです。

## 取り出す

棚からほかのアプリへドラッグで取り出すときは、Finder と同じ動きです。

| 取り出し方 | 動き |
|---|---|
| そのまま落とす | 同じボリュームなら**移動**、別のボリューム（外付けのディスクなど）なら**コピー** |
| ⌥ を押しながら落とす | コピー |
| ⌘ を押しながら落とす | 移動 |
| ⌘⌥ を押しながら落とす | エイリアスを作る |
| Dock のゴミ箱に落とす | ゴミ箱に入れる |

- 移動したもの・ゴミ箱に入れたものは、元の場所からなくなるので棚から外す。コピーしたときは棚に残す（設定の「中身」→「コピーで取り出したものも、棚から外す」をオンにすると、コピーでも外す）
- 選んでいるものをつかむと、まとめて取り出す。選んでいないものをつかむと、それだけを取り出す
- 移動かコピーかを決めるのは受け取る側のアプリ。Finder 以外のアプリ（メールなど）は、たいていコピーとして受け取る
- 外（Finder など）から棚へ落としたときは、場所を覚えるだけで、元のファイルは動かさない

### 棚から棚へ

| 落とし方 | 動き |
|---|---|
| そのまま落とす | 移動（元の棚から外れる） |
| ⌥ を押しながら落とす | コピー（元の棚にも残る） |
| 同じ棚に落とす | 何もしない |

- 浮いた棚から取り出すときも画面の端の棚が出るので、画面の端の棚へ移せる。取り出しながら振ると新しい棚が出るので、そこへ移すこともできる
- 移した先でも、再起動後に開ける

## ロック・スタック・元に戻す

### ロック

右クリックの「ロック」か ⌘L で、取り出しても棚に残るようにできます。ロックしたものには、アイコンの左下に鍵の印が付きます。

| 取り出し方 | ロックしていない | ロックしている |
|---|---|---|
| コピーで取り出す | 残す（「コピーで取り出したものも、棚から外す」がオンなら外す） | 残す |
| 移動で取り出す | 外す | 残し、新しい場所を指すようにする |
| ほかの棚へ移す | 外す | 残す（移した先にも置く） |

### スタック

一緒に置いた 2 つ以上のものは、1 つのスタックにまとまります（設定の「中身」→「一緒に置いた複数のものを、スタックにまとめる」で切り替え）。

- アイコンを重ねて件数を出す。押すと中身をまとめて選び、つかむとまとめて取り出す
- ダブルクリック・スペースキーで、中身を Quick Look で見る
- ポインタを乗せると左上に出るボタンか、右クリックの「スタックを分ける」で分ける。複数選んで右クリックの「選んだものをスタックにする」で、あとからまとめられる

### 元に戻す

棚から外したもの（× ボタン・delete・取り出して外れたもの）は、⌘Z か見出しの ↩︎ ボタンで、元の位置に戻せます。棚ごとに 20 回分まで覚えます（再起動すると忘れます）。

## クリップボードから棚へ

コピー中のものを棚に入れられます。

| 入口 | 入れ先 |
|---|---|
| どこからでも使えるショートカット（初期設定は ⌥⇧V） | 設定の入れ先（新しい棚をカーソルの位置に開く／画面の端の棚に入れる） |
| メニューバーの「クリップボードから棚へ」 | 設定の入れ先（新しい棚はアイコンの下に開く） |
| 棚の上で ⌘V・何もないところの右クリックの「貼り付ける」 | その棚 |

- Finder でコピーしたファイルはファイルとして、URL はリンク、文字はテキストとして入れる。コピーした画像（スクリーンショットをクリップボードに撮ったときなど）は、PNG のファイルにして入れる
- ショートカットは設定の「一般」→「メニューバーとクリップボード」で、使わない／⌥⇧V／⌃⌥V／⌃⇧V から選ぶ
- macOS が、ほかのアプリがコピーしたものを読む許可を求めることがある。そのときは「許可」を選ぶ

## メニューバー

メニューバーの Pinshelf のアイコンを押すと、次のメニューが出ます。

- 新しい棚を開く・画面の端の棚を開く・クリップボードから棚へ
- 最近閉じた棚 ▸（[最近閉じた棚](#最近閉じた棚)）
- お気に入り一覧…（[お気に入り一覧](#お気に入り一覧とお気に入りから削除)）
- お気に入りの棚（お気に入りの棚があるとき。選ぶと出す）・お気に入りから削除 ▸
- 設定…（⌘,）・Pinshelf を終了

アイコンには、ファイル・テキスト・リンクを落とせます。入れる棚は、設定の「一般」→「メニューバーとクリップボード」→「入れる棚」で選びます。

| 入れる棚 | 動き |
|---|---|
| 新しい棚を開く（初期設定） | アイコンのすぐ下に浮いた棚を開いて入れる |
| 画面の端の棚に入れる | 画面の端の棚に入れ、入ったことが分かるよう少しのあいだ開く |

## 棚の大きさ

棚の縁（辺と角）をマウスでつかんで運ぶと、ふつうのウィンドウと同じように大きさが変わります。

- 縁にポインタを乗せると、その辺・角がアクセントカラーで光る。棚を一度クリックしたあとは、ポインタも大きさを変える形になる（前面にないアプリはポインタの形を変えられないため）
- 大きさは 150×150 から 1000×1000 まで。中身は横幅に合わせて並び直す（列の数は横幅で決まるので、中身が増えても列は減らない）
- 画面の端にしまった棚は、開いたときに、画面の端の側以外で変えられる。帯だけのときは変えられない
- 棚は、画面の端にあるときと浮いているときの大きさを別々に持つ。しまう・浮かせるたびに、それぞれの大きさに切り替わる

### 標準の大きさ

新しく開く棚の大きさは、置き方ごとに決めます（画面の端にあるとき／浮いているとき）。

- 設定の「棚」→「棚の大きさ（標準）」で、幅と高さを数字で決められる。「初期値に戻す」で、画面の端にあるときは 150×240、浮いているときは 180×180 に戻る
- 「縁をつかんで変えた大きさを、標準にする」がオン（初期設定）なら、縁をつかんで変えた大きさが、そのときの置き方の標準になる
- 棚の … メニューの「大きさ」から、「この大きさを標準にする」「標準の大きさに戻す」も選べる（今の置き方の標準が対象）

## 棚のメニュー

見出しの … ボタン（見出しの右クリックでも同じ）のメニューです。

```
名前を変える…
色                          ›
お気に入り（閉じても残す）    ✓
画面の端で開いたままにする    ✓   ← 画面の端にある棚だけ（見出しのピンと同じ）
────────────
大きさ（浮いているときの標準）        ← 画面の端にあるときは「画面の端にあるときの標準」
この大きさを標準にする
標準の大きさに戻す
────────────
すべての棚
✓ 画面の端まで運んだら、自動でしまう
✓ 新しい棚は、画面の端で開いたままにする
設定を開く…
────────────
画面の端にしまう（しまっていれば「浮かせる」）
閉じる（お気に入りの棚は「隠す」）
```

「すべての棚」の 2 つは、設定画面の同じスイッチと同じものです。

## 名前・色・お気に入り

| 操作 | 動き |
|---|---|
| 名前を変える… | 見出しがそのまま入力欄になる。return で決める、esc でやめる。空にすると名前なし（件数を出す） |
| 色 | なし・赤・オレンジ・黄・緑・青・紫・グレー。見出しに色の点が付き、枠としまった帯にも色が付く |
| お気に入り（閉じても残す） | 閉じても中身ごと残し、メニューバーやお気に入り一覧から出し直せる。空でも残る。見出しの ★ を押しても切り替えられる |

- 見出しの左の ★ は、いつも出ている。お気に入りなら黄色の ★、そうでなければ線だけの ☆。押すたびに、お気に入りにする・外すが切り替わる
- 名前のない棚をお気に入りにすると、「棚 1」「棚 2」…と仮の名前を付ける
- お気に入りの棚の ✕ は「隠す」になる。お気に入りでない棚は、閉じると消える（中身があれば「最近閉じた棚」に入る）

### お気に入り一覧と、お気に入りから削除

メニューバーの「お気に入り一覧…」で、お気に入りの棚の一覧のウィンドウが開きます。

| 場所 | 出す | お気に入りから削除 |
|---|---|---|
| お気に入り一覧 | ダブルクリック・return・行の「出す」ボタン | 右クリック・delete キー（いくつか選んでまとめても消せる） |
| メニューバー | 「お気に入りの棚」の下の棚を選ぶ | 「お気に入りから削除 ▸」の中から棚を選ぶ |
| 棚の見出し | — | ★ を押す（… の「お気に入り（閉じても残す）」を外しても同じ） |

- 「お気に入りから削除」は、お気に入りから外すこと。出している棚は、ふつうの棚としてそのまま残る
- 閉じて隠していたお気に入りの棚は、外すとそのまま閉じる。「最近閉じた棚」に入るので、そこから開き直せる（空の棚は入らない）

## 最近閉じた棚

閉じた棚は 10 個まで覚えておき、メニューバーの「最近閉じた棚 ▸」から開き直せます。

- 覚えるのは、中身のある、お気に入りでない棚
- 一覧には、色・名前（なければ「議事録.pdf ほか 2 個」のような中身の名前）・件数・閉じた時刻（「5 分前」など）が出る
- 選ぶと、閉じたときの位置に、中身・名前・色ごと戻る。閉じている間に消えたファイルは戻らない
- 再起動しても開き直せる。一覧の下の「履歴を消す」ですべて忘れる

## 設定（メニューバーの「設定…」）

macOS の設定画面と同じく、上のタブで分けています。説明は、項目名の横の ⓘ を押すと出ます。

| タブ | 中身 |
|---|---|
| 一般 | ログイン時に起動・メニューバーとクリップボード（入れる棚・ショートカット）・バージョン |
| 出し方 | 画面の端に出す（出す端・出すとき・出す高さ）・カーソルの位置に出す（振る・感度・ドラッグ中に押すキー） |
| 棚 | 棚の大きさの標準（画面の端にあるとき・浮いているとき・縁で変えた大きさを標準にするか）・画面の端にしまう（自動でしまう・新しい棚を開いたままにするか） |
| 中身 | スタックにまとめるか・コピーで取り出したものも外すか・棚のキー操作の一覧 |
| 除外するアプリ | 棚を自動では出さないアプリ |

### ログイン時に起動

設定の「一般」で入れたり外したりできます（初期設定はオフ）。システム設定の「ログイン項目」で変えても、設定画面に反映されます。macOS の許可が要るときは、その旨と「ログイン項目を開く」ボタンが出ます。

## 再起動したとき

- 棚の中身・位置・大きさ・名前・色・お気に入り・しまっているか・ピンを残し、再起動しても元に戻す
- ファイルは、終了している間に移動・名前を変えても、新しい場所で戻る。見つからなくなったファイル（消したものなど）は戻さない
- 画面の端の棚は、中身があれば件数つきの帯で戻る。外した画面にあった棚は、今の画面に移す

## 動き

棚の出し入れと、帯と棚の切り替えはアニメーションで動きます。

- 帯と棚の切り替え: 帯がフェードで棚に変わりながら、棚が端から引き出しのように開く。たたむときは、棚が見えたまますぐに動き出し、画面の端に向かってなめらかに止まりながら帯に変わる
- 画面の端の棚・帯が出る・消える: 画面の端の外から滑り込み、端の外へ滑り出る
- 浮いた棚が出る・消える: 少し小さい状態からふわっと大きくなり、閉じると小さくなりながら消える
- ドラッグで重ねると、帯・棚の縁がアクセントカラーで光る
- システム設定 → アクセシビリティ → 表示 →「視差効果を減らす」がオンなら、動きを短いフェードだけにする
